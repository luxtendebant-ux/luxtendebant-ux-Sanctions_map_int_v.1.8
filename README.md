# Санкционный дайджест — автоматический выпуск

Эта ветка обслуживает [Комплаенс-карту](https://luxtendebant-ux.github.io/luxtendebant-ux-Sanctions_map_int_v.1.8/). Здесь лежат инструмент сборки, журнал выпусков и готовые PDF. В ветке `main` по-прежнему один файл карты — `index.html` (плюс служебный файл запуска в `.github/workflows`).

## Как это работает

1. В `main` публикуется новый срез карты.
2. GitHub сам запускает сборку (1–2 минуты, без участия ИИ).
3. Инструмент смотрит, какие карточки изменились, и отбирает ключевые события — новые включения российских компаний и лиц в санкционные списки.
4. Если такие события есть, собирается PDF в фирменном оформлении и кладётся в папку `out`; на странице Releases появляется запись о выпуске.
5. Если ключевых событий нет, ничего не выпускается. В отчёте запуска видно решение по каждой изменившейся карточке и причину.

Одно событие попадает в дайджест один раз: повторная сверка карточки или повторная редакция среза нового выпуска не вызывает.

## Что считается ключевым событием

| Условие | Результат |
|---|---|
| Новая карточка в разделах санкций (США, ЕС, Великобритания, Канада, Швейцария, Австралия / Япония / НЗ, G7) о включении лиц, компаний или судов; статус «Действует» или «Принята, не вступила» | выпуск дайджеста |
| Обновлённая карточка о включении, дата события — между прошлым и текущим срезом | выпуск дайджеста |
| В карточке о включении упомянуты ИНК, ИНК-Капитал, Irkutsk Oil | тот же выпуск с пометкой `_INK` в имени файла и слайдом выдержек |
| Включение ещё не принято (статус «В процессе принятия», «Заявлено официально») | строка в блоке «На подходе», сам по себе выпуск не вызывает |
| Новости, продления, лицензии, исключения из списков, судебные дела, ценовой потолок — в том числе с упоминанием ИНК | дайджест не выпускается; если выпуск вызван другим событием — строка в блоке «Также изменилось в карте» |

Правила отбора — в `tool/config.json`, раздел `events`. Список наблюдения — там же, раздел `watchlist`; репозиторий открытый, поэтому в списке только наименования, которые уже есть в открытой части карты.

## Управление из карты

Правила отбора можно переопределить прямо в карточке, добавив поле `digest`:

- `"digest": true` — карточка обязательно идёт в дайджест;
- `"digest": false` — карточка в дайджест не идёт никогда.

При обновлении карты в то же поле можно положить готовые материалы, и они встанут отдельными блоками:

```json
"digest": {
  "quotes": [{"text": "дословная цитата с сайта регулятора", "url": "https://…"}],
  "lists": [{"title": "Физические лица", "items": ["…", "…"]}],
  "conclusions": ["вывод 1", "вывод 2"],
  "forecast": ["прогноз на квартал 1", "прогноз на квартал 2"]
}
```

## Защита паролем

В `tool/config.json` стоит `"publish": {"mode": "encrypted"}`: PDF публикуется только зашифрованным (AES-256). Пароль задаётся один раз в настройках репозитория: Settings → Secrets and variables → Actions → New repository secret, имя `DIGEST_PDF_PASSWORD`. Пока секрет не задан, дайджест не выпускается, а запуск завершается с ошибкой — GitHub пришлёт об этом письмо.

Чтобы публиковать без пароля, замените `encrypted` на `open`. Репозиторий открытый: файл без пароля сможет скачать любой, у кого есть ссылка.

## Ручной запуск

Вкладка Actions → «Санкционный дайджест» → Run workflow:

- `normal` — обычный выпуск;
- `dry-run` — только показать, какие события были бы отобраны;
- `force` — выпустить дайджест по текущему срезу заново.

## Что дайджест не делает

- Не ищет новости и не проверяет регуляторов. Он узнаёт о событии только после того, как оно внесено в карту, поэтому скорость выпуска равна частоте обновления карты.
- Не добавляет ничего от себя. Каждый факт взят из карты дословно; уровень источника и дата сверки указаны по карте. Проверка `tool/tests/check_pdf_against_map.py` подтверждает, что в PDF нет ни одного числа, которого нет в карте.
- Не читает закрытый раздел карты: он зашифрован. Оценка последствий для группы в автоматический дайджест не попадает.

## Состав

| Файл | Назначение |
|---|---|
| `tool/build_digest.py` | сборщик: чтение карты, отбор событий, вёрстка PDF |
| `tool/template.html` | оформление слайдов |
| `tool/config.json` | настройки: правила отбора, список наблюдения, тексты колонтитулов, режим публикации |
| `tool/assets/` | логотип и фон разделителей (без них слайды собираются в нейтральном оформлении), шрифт Inter (лицензия OFL — `fonts/OFL.txt`) |
| `tool/tests/` | самопроверка логики и сверка PDF с картой |
| `ledger.json` | журнал: какие события уже вошли в дайджесты |
| `out/` | готовые PDF |
